# Trademark And Brand Guidelines

This document explains how the SurroundStreamer project name, logos, icons, and related brand
assets may be used.

## Software License Scope

The SurroundStreamer software code is licensed under the MIT License. See [LICENSE](LICENSE).

The MIT License does not grant rights to use the SurroundStreamer name, Non-REM Studio name, logos,
icons, banner images, application artwork, or other brand assets except as described here or with
separate permission from Non-REM Studio.

## Brand Assets

The following materials are brand assets and are not licensed under the MIT License:

- The `SurroundStreamer` project and application name when used to identify an official release.
- SurroundStreamer logos, icons, and banner images.
- Non-REM Studio names, logos, and brand identifiers.
- Tia Rungray names, logos, and artist/brand identifiers.
- Application artwork and brand images in `resources/` and `src/renderer/public/brand/`.

These assets are Copyright (c) 2026 Non-REM Studio unless otherwise stated.

## Allowed Uses

You may use the SurroundStreamer name to:

- Refer to the original project.
- Link to the official repository or releases.
- State that your project is a fork of, based on, or compatible with SurroundStreamer.
- Include unchanged notices and attribution required by the MIT License and third-party licenses.

## Modified Versions

If you distribute a modified version, do not present it as an official SurroundStreamer release.

Modified versions should:

- Use a different application name unless permission is granted.
- Replace the official logos, icons, and banner images.
- Clearly state that the build is modified and not provided by Non-REM Studio.
- Avoid implying endorsement, certification, or support by Non-REM Studio or Tia Rungray.

## Official Releases

Official SurroundStreamer releases are published by Non-REM Studio through the official repository
and release channels.

If you want to use the SurroundStreamer name or brand assets in a way not covered here, contact
Non-REM Studio for permission.
