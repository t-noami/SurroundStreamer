# SurroundStreamer v0.1.2

**macOS Apple Silicon release.**

SurroundStreamer v0.1.2 updates the macOS monitor and streaming workflow. It sends audio from an audio interface or audio file to an Icecast/Shoutcast-compatible streaming server as **Ogg Opus surround audio**, **stereo MP3**, or both.

## Download

### macOS Apple Silicon

- `SurroundStreamer-0.1.2.dmg`

Requires macOS 14.2 or later on Apple Silicon.

## What's New

- Restored multichannel monitor downmix routing.
- Sends the streaming monitor to the output device selected in the app.
- Adds CBR, CVBR, and VBR Opus bitrate mode controls.

## Platform Availability

- This GitHub Release contains a newly built macOS v0.1.2 DMG only.
- Windows x64 remains at v0.1.1; its existing installer is not rebuilt or reattached here.
- Linux x64 AppImage remains at v0.1.1; its existing artifact is not rebuilt or reattached here.

## Notes

- App Audio capture is not a supported input source. Use Audio Input with a physical, virtual, or loopback device.
- The macOS package includes the Core Audio helper for Audio Input capture and the vetted macOS FFmpeg binary with matching notices and license texts.
- This artifact is ad-hoc signed; it is not notarized.
