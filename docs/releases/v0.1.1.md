# SurroundStreamer v0.1.1

Release notes for the macOS stable release.

## Download

- `SurroundStreamer-0.1.1.dmg`

## Scope

- Input sources: Audio Input and File.
- App Audio capture: removed from the supported input-source UI.
- macOS Audio Input: Core Audio helper PCM capture.
- File source: playback, monitor preview, and streaming.
- Encoding formats: Ogg Opus over Icecast, Ogg Opus plus stereo MP3, and Stereo MP3 only.
- MP3 destinations: MP3 Icecast and MP3 Shoutcast 1.
- Standard channel templates: Mono, Stereo, Stereo + C, 5.1, and 7.1.

## UI Changes

- Added About/License window with MIT license and KU100 attribution.
- Moved Logs, GitHub Repository, and About actions to native application menus where applicable.
- Added `ヘルプ > GitHub Repository` to the macOS application menu.
- Added a stream-start loading overlay, validation field highlights, and a connection-failure dialog.

## Platform Notes

- macOS remains the stable public-release target.
- Windows backend work remains beta/pre-release until signing, broader ASIO compatibility, channel-order documentation, and long-run stability checks are complete.
- Linux Audio Input capture is not implemented.
