# SurroundStreamer v0.1.2

Release notes for the macOS stable release.

## Download

- `SurroundStreamer-0.1.2.dmg` (macOS 14.2 or later on Apple Silicon)

## What's New on macOS

- Restored multichannel monitor downmix routing.
- Routes the streaming monitor to the selected output device.
- Adds selectable Opus bitrate modes: CBR, CVBR, and VBR.

## Platform Scope

- This release updates the macOS Apple Silicon artifact only.
- Windows x64 remains on v0.1.1. Its installer is not rebuilt or attached to this release.
- Linux x64 AppImage remains on v0.1.1. Its artifact is not rebuilt or attached to this release.

## Verification

Performed for the macOS artifact:

- `npm run lint`
- `npm run build:mac`
- `codesign --verify --deep --strict --verbose=2 dist/mac-arm64/SurroundStreamer.app`
- `hdiutil verify dist/SurroundStreamer-0.1.2.dmg`
- Mounted the DMG and confirmed the packaged app version.

## Notes

- The macOS package is ad-hoc signed; notarization is disabled in the current Electron Builder configuration.
- Release packages include the platform-specific FFmpeg binary with matching notices and license texts.
