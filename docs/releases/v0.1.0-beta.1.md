# SurroundStreamer v0.1.0-beta.1

Initial public beta release for macOS Apple Silicon.

> Historical release note: this describes the old `0.1.0-beta.1` macOS beta. The current beta build line is `0.1.1-beta.10` with app name `SurroundStreamer-beta-0.1.1`, and App Audio has been removed as a supported input source.

## Historical Download

- `SurroundStreamer-beta-0.1.0-0.1.0-beta.1-arm64-mac.zip`

## Supported Platform

- macOS on Apple Silicon

Windows and Linux build notes are included in the repository for future platform work, but the current audio capture implementation depends on macOS Core Audio.

## Highlights

- Ogg Opus streaming to Icecast.
- App Audio capture using Core Audio process taps.
- Audio Input capture through the Core Audio helper path.
- File source playback and streaming.
- Standard stream channel templates: Mono, Stereo, Stereo + C, 5.1, and 7.1.
- Monitor Output for App Audio and File sources.
- Monitor modes: Stereo Pair, Stereo Downmix, and KU100 Near-field HRIR.
- Persistent Icecast connection settings.
- Stream Playback Check documentation for `https://non-rem.com/SurroundWebPlayer/`.
- MIT License added for the application source.

## Known Limitations

- This is a beta build.
- The app is ad-hoc signed and not notarized.
- Audio Input Monitor Output requires macOS microphone permission and a valid Core Audio audio input.
- 7.1.2 and 7.1.4 are not included in the standard build.
- Windows and Linux packages were not release-ready for this beta. The later beta branch now has a Windows ASIO/MMDevice Audio Input backend; Linux Audio Input remains unimplemented.
