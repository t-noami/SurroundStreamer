# SurroundStreamer v0.1.1

SurroundStreamer v0.1.1 focuses the app on Audio Input and File sources, adds packaging-ready FFmpeg handling, and includes a Windows beta installer for broader validation.

macOS remains the primary stable release target. The Windows build is provided as a beta/pre-release artifact while signing, SmartScreen reputation, broader ASIO device compatibility, channel-order documentation, and long-run stability checks continue.

Linux packages are not published for this release because Linux Audio Input capture is not implemented yet.

## Highlights

- Audio Input and File are now the supported input sources.
- App Audio capture has been removed from the supported input-source UI.
- File source supports playback, monitor preview, and streaming.
- File selection now includes common audio containers such as WAV, FLAC, Ogg/Opus, M4A/AAC, MP3, AIFF/AIF, and CAF.
- Ogg Opus streaming, Ogg Opus plus stereo MP3, and Stereo MP3 only modes are supported.
- Standard stream channel templates remain Mono, Stereo, Stereo + C, 5.1, and 7.1.
- Monitor Output includes Stereo Pair, Stereo Downmix, and KU100 Near-field HRIR modes.
- Logs, GitHub Repository, and About actions are available from native application menus where applicable.
- Stream startup now shows a loading overlay, validates required fields visually, and reports connection failures in a dialog.

## Windows Beta Notes

The Windows beta build includes:

- Native ASIO Audio Input capture.
- MMDevice/WASAPI Audio Input capture.
- DirectShow fallback when the native helper is unavailable.
- Backend-owned FFmpeg/WASAPI monitor rendering for ASIO Audio Input and File-source monitoring.
- Wizard-based NSIS installer with desktop and Start Menu shortcuts.
- Bundled Windows x64 FFmpeg binary built from FFmpeg 8.1.

For surround Audio Input streaming on Windows, use an ASIO-capable audio interface or ASIO virtual audio device with 6 or more input/output channels. WASAPI/MMDevice endpoints are useful for mono/stereo inputs, but should not be assumed to expose surround capture.

## FFmpeg And Third-Party Notices

Release packages no longer use the `ffmpeg-static` npm package. They include vetted platform-specific FFmpeg binaries with matching notices and license texts.

The Windows package includes a custom LGPL-compatible FFmpeg 8.1 build with libopus and libmp3lame enabled. AIFF/AIF and CAF support is provided by FFmpeg's built-in LGPL demuxers and does not add an external library license.
